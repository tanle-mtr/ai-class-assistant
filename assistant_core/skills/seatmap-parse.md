# 技能：座位表解析

将座位表（图片识别结果或文字描述）转换为结构化座位表数据，供点名、换座检测使用。

## 输入格式
用户提供：
- 图片 OCR 结果（由 image-ocr 技能转写，含行列布局与名字）
- 或座位表的文字/表格描述
- 班级人数（可选）

## 输出格式
严格输出 JSON（不要输出其他内容）：
```json
{
  "class_name": "高一(3)班",
  "rows": 6,
  "cols": 8,
  "updated": "2026-09-24",
  "seats": [
    {"row": 1, "col": 1, "name": "张三"},
    {"row": 1, "col": 2, "name": "李四"}
  ],
  "unresolved": ["无法识别的名字列表"]
}
```

## 要求
- 行号从上到下递增，列号从左到右递增
- 名字必须来自输入，不得编造；识别不清的名字放入 unresolved
- 讲台位置不纳入座位表（默认上方为讲台）
