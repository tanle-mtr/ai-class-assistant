# 技能：纯文本 AI 识图（Image to Text）

本技能让**纯文本大模型也能"看懂"图片**：当任务需要理解一张图片（截图、扫描件、照片、教科书页面、座位表）时，
先调用本地视觉模型把图片转成文字描述/OCR 结果，再把文字结果作为素材参与后续任务。

## 使用流程（调用方执行）
1. 确认图片路径存在
2. 调用视觉引擎（assistant_core.ai.vision.vision）：
   - `describe(image_path, question)`：按需提问得到图片描述
   - `ocr(image_path)`：逐字识别图片文字（扫描件、表格按行列输出）
3. 把视觉模型返回的文字结果，作为"图片转写素材"拼接进本任务的上下文
4. 由纯文本主力模型基于转写素材完成后续分析/总结/问答

## 适用场景
- 教科书扫描页 → OCR 转文本 → 进知识库或直接问答
- 座位表图片 → 描述布局与名字 → 生成座位表 JSON
- 课件截图/板书照片 → 描述内容 → 并入课堂总结素材
- 试卷照片 → OCR → 并入评讲分析

## 注意事项
- 视觉模型未安装时返回占位说明，此时提示用户 `ollama pull gemma3:1b` 或 `ollama pull qwen2.5vl:3b`
- 低质量图片可要求视觉模型"先描述整体再逐区识别"
- 若图片文字模糊，提示"（图片清晰度不足，识别结果可能不全）"
