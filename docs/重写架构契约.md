# AI 课堂助手 — 全量重写架构契约 v2

> 2026-11-24 · 本文件是 Python 核心 / Vue 控制台 / C# 托盘三层**并行开发的唯一对齐依据**。
> 任何层不得擅自修改本契约中的端点路径与响应字段；如需变更，先改本文件再通知其它层。

## 0. 重写原则

- **全量推倒**：三层代码全部从零写，不复用 v1 的实现（可阅读 v1 以理解需求，但不得照搬文件）。
- **顶层目录名保留**：`assistant_core/` / `webui/` / `tray/` 不变（CI / spec / 脚本路径依赖它们），**内部文件全部重写**。
- **需求不变**：以 `docs/需求规格.md` §1–§12 为准，UI 以 `docs/ui-design/01–04` 效果图为准。
- **数据兼容**：`data/` 下用户既有数据（config.json / seatmap.json / exports / recordings）**必须能读**，不得清空或改格式。
- **隐私默认值**：`monitor_always_record=false`，无人上课时不落盘；取流仅用于分贝/就座率分析。

## 1. 技术栈与端口

| 层 | 技术 | 说明 |

| Python 核心 | Python 3.11+ / FastAPI / uvicorn | 业务、感知、AI、Web API |
| Vue 控制台 | Vue 3 + Vite 5 | 浏览器界面 + 桌面 panel.html |
| C# 托盘 | .NET 8 WinForms | 托盘、原生主面板、ClassIsland IPC 桥 |

端口分配（被占用时依次顺延，桥端口 18761 保留专用）：

| 端口 | 用途 |
|---|---|
| 18760 | Web 控制台 API + 静态托管 `webui/dist` |
| 18761 | C# ClassIsland 桥（HTTP，供 Python 轮询） |
| 5244 | OpenList（可选） |

Python 核心启动流程：读 config → 起感知线程 → 起 FastAPI(18760，占用则顺延) → 写回实际端口到 config。

## 4. API 契约（必须严格实现，字段不可改名）

所有响应为 JSON；错误用 `{"ok": false, "error": "..."}`；字段缺失时返回空值而非省略。

### 核心
| 方法 | 路径 | 响应 |
|---|---|---|
| GET | `/api/health` | `{ok:true}` |
| GET | `/api/state` | `{session,model,vision_model,monitor_enabled,record_camera,record_audio,monitor_always_record,tunnel,public_ip}` |
| GET | `/api/db` | `{samples:[number],avg_db:number,peak_db:number,per_minute:[{min,avg}],count:int}` — **samples 必须是数字数组** |
| GET | `/api/schedule` | `{date,items:[{subject,start,end,type}],source}` |
| POST | `/api/monitor` | body `{enabled?:bool,always_record?:bool}` → `{ok,monitor_enabled,monitor_always_record}` |
| POST | `/api/shutdown` | `{ok:true}` — 优雅停机：停感知线程、关 writer、导出、退出 |
| GET | `/api/public_ip` | `{ip}` |

### AI
| 方法 | 路径 | 响应 |
|---|---|---|
| GET | `/api/models` | `{models:[{name,size}],current,vision_models:[name],hardware:{cpu,cores,ram_gb,gpu,vram_gb,advice}}` |
| POST | `/api/models/select` | body `{model}` → `{ok,model}` |
| POST | `/api/models/create` | body `{name,base_model?}` → `{ok,name,base_model,msg}` |
| POST | `/api/summarize` | 无 body → `{ok,error?}` 异步触发当前会话总结 |
| POST | `/api/export` | 无 body → `{ok,error?}` 异步触发导出 |

### 文件与课件
| 方法 | 路径 | 响应 |
|---|---|---|
| GET | `/api/summaries` | `[{date,courses:[{name,files:[{name,size,url}]}]}]` |
| GET | `/api/files/{date}/{course}/{filename}` | 文件下载（防路径穿越） |
| GET | `/api/file/content` | query `date,course,name` → `{name,content}`（防路径穿越） |
| POST | `/api/upload` | form `subject,file` → `{ok,name,subject}`；科目不存在时自动创建 |
| GET | `/api/courseware` | `{subjects:[name],files:[{name,subject,size}]}` |

### 教科书 / 座位 / 隧道
| 方法 | 路径 | 响应 |
|---|---|---|
| GET | `/api/textbook/status` | `{ready,chunks,grade,region,books:[name]}` |
| POST | `/api/textbook/match` | body `{grade,region}` → `{books:[name]}` |
| POST | `/api/textbook/import` | form `file`(PDF) → `{ok,chunks,msg}` |
| POST | `/api/textbook/ask` | body `{question}` → `{answer,sources:[{book,page,score}]}` |
| GET | `/api/seatmap` | `{class_name,seats:[{id,row,col,name,face_id}]}` |
| POST | `/api/seatmap/init` | form `file`(图片) → `{ok,seats}` |
| GET | `/api/seatmap/export` | 导出 md 文件下载 |
| POST | `/api/tunnel/token` | body `{token}` → `{ok}` |
| POST | `/api/tunnel/start` | → `{ok,msg,url?}` |
| GET | `/api/tunnel/rules` | → `[{id,port,name,enabled,url}]` |
| POST | `/api/tunnel/proxy` | body `{port,name,enabled}` → `{ok,rules}` |
| POST | `/api/tunnel/login` | → `{ok,msg}` |

## 8. 验收标准

1. `python -m compileall -q assistant_core` 通过；`vite build` 通过；两个 `.csproj` `-warnaserror` 构建 0 警告 0 错误。
2. 真实启动 `python -m assistant_core.cli`，全部 API 返回正常 JSON，无 500；`/api/db` 无会话不崩。
3. CDP 无头截图对照效果图 01–04，布局/配色/元素齐全。
4. 本机旧数据可读取；无人上课时不产生新的监控媒体文件。
5. 提交推送后 GitHub Actions CI 全绿。
