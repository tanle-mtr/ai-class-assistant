## 一、总体结论

骨架是完整且分层清晰的（Python 核心 / C# 托盘 / Vue 控制台 / PowerShell 脚本四层都对得上需求），
**但存在 5 个会直接导致功能失效的运行时缺陷**，以及**一批"写了但没接线"的孤儿模块**——
函数实现了却没有任何地方调用，需求对应的功能实际上不存在。

粗略估计：需求**约 60% 已真正可用**，20% 有实现但失效/未接线，20% 完全缺失。

## 二、A 类：会导致崩溃或功能必然失效的缺陷（必须修）

### A1. `/api/db` 分贝接口必然 500 崩溃
`assistant_core/web/server.py:59-66`

```python
samples = list(a.session.db_samples[-120:])   # 元素是 {"sec":..., "db":...} 字典
avg = round(sum(samples) / len(samples), 1)    # sum([dict, dict]) → TypeError
peak = max(samples)
```

只要上课中（有会话、有分贝样本），这个接口就抛 `TypeError: unsupported operand type(s) for +: 'int' and 'dict'`。
前端 `App.vue` 每 10 秒轮询一次，`panel.html` 也在轮询 → 分贝波形和平均分贝**全程不可用**。
同时前端 `samples()` 把样本当数字数组画折线图（`v / 140`），类型也对不上。
**影响需求**：§4 分贝监控、§5 考试/自习课分贝折线图 + 平均分贝。

### A2. 拖堂判定永远不会触发
`assistant_core/main.py:214-227`

`_check_overtime_window()` 只在 `state == "OnClass"` 分支里被调用；
下课后状态变为 `Breaking`，走的是另一个分支，进入拖堂观察窗口后**再没有任何采样**：

```python
elif state in ("Breaking", "None", "AfterSchool"):
    if self.session is not None:
        if state == "Breaking" and not self.session.end_time:
            self._begin_overtime_check()      # 只起了个计时窗口
        if self._overtime_check_passed():
            self._end_session()               # 窗口内从不判定
```

结果 `session.overtime_detected` 恒为 `False`。
**影响需求**：§4 拖堂判定（屏幕活跃 + 学生未离座）、§5 老师总结的"防拖堂建议"。

### A3. 摄像头人脸建档完全没跑
`assistant_core/perception/camera_capture.py:138`

```python
def _analyze(self, frame):
    ...
    if self._session and int(now) % 30 < self._analyze_interval:   # now 在本作用域未定义
```

`now` 只在 `_on_frame` 里定义，`_analyze` 里没有 → `NameError`，被外层 `except` 静默吞掉。
连带下一行的占位垃圾代码 `seat = f"{int((y) // (h // grid_rows) if False else 0)}"` 一起失效。
**影响需求**：§7 上课时摄像头自动录入学生人脸建档。

### A4. 录音文件句柄未关闭 → 上一段 WAV 损坏
`assistant_core/perception/audio_capture.py:88` `start_recording()`

上课开始时直接 `self._wav = wave.open(...)` 覆盖了正在写的"监控切片"句柄，
旧 `Wave_write` 从未 `close()` → 旧文件缺少 WAV 头，播放不了，且句柄泄漏。

### A5. `config.py` 缺少 `import os`
`assistant_core/config.py:104` 在 `except` 分支里用 `os.cpu_count()`，但文件顶部只导入了
`platform / subprocess / sys / json / dataclasses / pathlib`。psutil 缺失时才会触发，但属于必崩路径。

## 四、C 类：与需求描述不符

### C1. 评讲课缺导学案（§5）
需求表格明确要求：评讲作业/试卷课 = 老师总结 + 学生总结 + **导学案**（不出思维导图）。
当前 `summarizer.py:128-136` 评讲课只生成 `review_questions`（变式练习），**没有导学案**。

### C2. 总结视图没有渲染（§10 效果图 04）
`App.vue:374-381` 点"查看"只是 `window.open(s.url)` 打开原始 `.md` 源文件，
思维导图（Markmap）完全没有渲染，老师总结/学生总结也不是渲染后的版式 → 与效果图 04 不符。

### C3. 前端大量硬编码假数据
- `timeline`（今日课程时间线）：写死"语文/数学/英语/物理"四节课，未接 ClassIsland 课表
- `adviceList`（细讲/缩短/防拖堂建议）：写死三条假文案
- 思维导图卡片：写死"二次函数 / 定义 / 图像 / 应用"
- `subjects`（科目列表）：写死 9 个，不从 `/api/courseware` 同步已建科目 → §10"没有的科目自动创建"不闭环

### C4. 屏暈分析结果未进入总结上下文
`screen.activity_history()` 有采集，但 `_build_context()` 没用 → §5 节奏分析少了屏幕维度。
