# AI 课堂助手 — UI 设计（效果图 v1）

> 生成日期：2026-09-24 · 风格：教育科技风（深青色主色 + 白底圆角卡片 + 浅灰背景，避免大面积紫色）

## 设计规范（各界面统一遵循）

| 项目 | 取值 |
|---|---|
| 主色 | 深青色 #0F766E（导航栏、主按钮、高亮） |
| 强调色 | 青色 #14B8A6（进度、波形、图标） |
| 背景 | 浅灰 #F1F5F9 / 白色卡片 #FFFFFF |
| 卡片 | 圆角 12px，浅灰 1px 描边，轻阴影 |
| 字体 | 无衬线（中文：思源黑体/微软雅黑），标题加粗、深灰 #0F172A，正文 #334155 |
| 状态色 | 绿色（运行中/已连接/已完成）、琥珀色（预警） |

## 界面清单

| 图 | 界面 | 用途 |
|---|---|---|
| 01 | 桌面托盘主面板 | 常驻托盘的软件主界面：当前课程、下课倒计时、课堂记录、模型选择、拖堂监测、快捷操作 |
| 02 | 网页控制台总览 | 远程数据中心：统计卡、今日课程时间线、课堂总结列表、导出文件浏览（OpenList） |
| 03 | 课件上传页 | 老师远程上传课件：拖拽区、科目分类标签（可新建科目）、上传进度 |
| 04 | 课堂总结视图 | 课后产物渲染：老师总结（质量星级/细讲/缩短/防拖堂）、学生总结（重难点）、思维导图、分贝折线图 |

## 说明

- 效果图为 AI 生成的方向稿，界面文字为示意，正式实现以真实数据渲染为准。
- 桌面托盘（图 01）由 C# 实现；网页控制台/上传页/总结视图（图 02-04）由 Vue 前端实现。
