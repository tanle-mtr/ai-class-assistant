## 0. 根本变化（相对 v1/v2）

| 项 | v1/v2 | v3 |

## 2. 核心类型（各层共同引用，字段不可改名）

```csharp
namespace AiClassAssistant.Core.Models;

public enum LessonState { None, OnClass, Breaking, AfterSchool }
public enum LessonType  { New, Review, Exam }

public sealed class LessonInfo
{
    public string Subject { get; set; } = "";
    public string ClassName { get; set; } = "";
    public string Start { get; set; } = "";   // "09:35"
    public string End { get; set; } = "";     // "10:15"
    public LessonType Type { get; set; } = LessonType.New;
    public int Index { get; set; }
}

public sealed class DbSample { public long Sec { get; set; } public double Db { get; set; } }
public sealed class AsrSegment { public long Ts { get; set; } public string Text { get; set; } = ""; }

public sealed class Session
{
    public string Id { get; set; } = "";
    public LessonInfo Lesson { get; set; } = new();
    public DateTime StartTime { get; set; }
    public DateTime? EndTime { get; set; }
    public List<DbSample> DbSamples { get; } = new();
    public List<AsrSegment> AsrSegments { get; } = new();
    public List<string> CameraSegments { get; } = new();
    public string? AudioFile { get; set; }
    public bool OvertimeDetected { get; set; }
    public Dictionary<string, string> Outputs { get; } = new();
    public bool IsActive => EndTime == null;
}

public sealed class Seat
{
    public string Id { get; set; } = "";
    public int Row { get; set; }
    public int Col { get; set; }
    public string Name { get; set; } = "";
    public string FaceId { get; set; } = "";
}

public sealed class SummaryDoc
{
    public string Title { get; set; } = "";
    public string Meta { get; set; } = "";
    public int Stars { get; set; }
    public List<string> Advice { get; set; } = new();     // 细讲/缩短/防拖堂
    public List<string> KeyPoints { get; set; } = new();
    public List<string> Difficulties { get; set; } = new();
    public string MindmapMarkdown { get; set; } = "";
    public List<double> DbSamples { get; set; } = new();
    public double AvgDb { get; set; }
    public double PeakDb { get; set; }
    public string RawMarkdown { get; set; } = "";
}
```

## 4. 关键业务逻辑（不可重犯的坑）

1. **拖堂判定**：`Breaking` 状态下每个 tick 都要 `screen.ForceSample()` + 读 `camera.SeatedRatio`，观察窗口 `overtime_check_seconds`（默认 120）结束后才 `session.OvertimeDetected = ...`。不能只在 OnClass 分支采样。
2. **隐私**：`monitor_always_record=false` 时，无人上课不写任何 AVI/WAV；取流继续（分贝/就座率需要）；`CloseAutoWriters()` 要在关开关时立即调用，且 session 非空时不误伤上课录像。
3. **人脸建档**：`_analyze` 内自己取 `DateTime.UtcNow`，6x8 网格 `r{行}c{列}`，每 30s 建档一次；不要引用作用域外的 now。
4. **录音句柄**：开始上课前先关闭旧 WAV 句柄，避免旧文件头损坏。
5. **Ollama 模型名**：`/api/tags` 返回带 tag（如 `qwen3:1.7b`），匹配时去 tag 归一化比较。
6. **评讲课也要导学案**（需求 §5），不出思维导图；考试自习课只出老师总结 + 分贝报告。
7. **换座检测**：上课中 + 下课时把 `camera.CollectObservations()` 交给 `SeatmapService` 更新座位表并导出。
8. **Ollama 不可用**：所有 AI 调用返回明确错误文本，界面显示"AI 服务不可用"，不抛异常、不白屏、不崩溃。
9. **数据兼容**：读取现有 `data/config/config.json`、`data/seats/seatmap.json`、`data/exports/**`，不删不改用户数据。

## 8. 技术备注

- NuGet 已验证可还原：NAudio 2.2.1、OpenCvSharp4 4.10.0.20240622、ClassIsland.Shared.IPC 1.6.0。
- OpenCvSharp 需要运行时原生 DLL：`OpenCvSharp4.runtime.win` 包要一并引用，否则运行时报 DllNotFound。
- 主程序输出如果是 WinExe，`NotifyIcon` 需配合 `Application.Run()` 与 `ApplicationContext`。
- 全解决方案统一 `net8.0-windows`，`UseWindowsForms=true`（类库也要开，才能用 Graphics）。
